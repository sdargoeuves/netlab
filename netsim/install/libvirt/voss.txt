Creating initial configuration for Extreme VOSS / Fabric Engine (8.10.x)
=======================================================================

* Boot the VM and wait for the prompt
* Login as 'rwa' (password: 'rwa')
* You will be prompted to change the password: set it to 'rwa'
  (do not use a different password, this is what netlab expects)
* Enter enable mode ('enable')
* Enter configuration mode ('conf t')

NOTE: management traffic is isolated in a dedicated management VRF/instance
(MgmtRouter), with DHCP enabled by default.

* Create the file which will contain the Vagrant public key:
    editing /intflash/rsa_key_rwa

* (IMPORTANT) Inside 'editing' mode:
  * press 'i' (insert mode)
  * press Enter once to go to line '1>'
  * paste the full key (one single line):
    ssh-rsa AAAAB3NzaC1yc2EAAAABIwAAAQEA6NF8iallvQVp22WDkTkyrtvp9eWW6A8YVr+kz4TjGYe7gHzIw+niNltGEFHzD8+v1I2YJ6oXevct1YeS0o9HZyN1Q9qgCgzUFtdOKLv6IedplqoPkcmF0aYet2PkEDo3MlTBckFXPITAMzF8dJSIFo9D8HfdOV0IAdx4O7PtixWKn5y2hMNG0zQPyUecp4pzC6kivAIhyfHilFR61RGL+GPXQ2MWZWFYbAGjyiYJnAmCP3NOTd0jMZEnDkbUvxhMmBYSdETk1rRgm+R4LOzFUGaHqHDLKLX+FIPKcF96hrucXzcWyLbIbEgE98OHlnVYCzRdK8jlqm8tehUc9c9WhQ== vagrant insecure public key
  * press Enter (you should see '2>')
  * press Esc, then ':w'
  * when prompted 'save to file [/intflash/rsa_key_rwa]:' press Enter

* Verify the key is available:
  more /intflash/rsa_key_rwa

* Install the key:
  ssh install-user-key rwa public rsa

Expected output:
  Info: Successfully installed the public key to rsa_key_rwa

If you get an error, delete the file, and start again, following the steps described above.
  delete /intflash/rsa_key_rwa -y
  editing /intflash/rsa_key_rwa

* Configure the following
# Disable ZTP+ and IQagent (IQCloud)
application
  no iqagent enable
  no auto-provision enable
  exit
# Disable the management vlan
  no mgmt vlan
# Save the configuration:
  save config
